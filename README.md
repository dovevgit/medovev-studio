# סטודיו לאסטרטגיה עסקית — medovev.com

אתר הסטודיו. דף הבית נפתח במסע גלילה (scroll-driven video scrubbing): שלושה
קליפים שמתנגנים לפי מיקום הגלילה, פריים אחר פריים, כשכל קליף מתחיל בדיוק
בפריים שבו הקודם נגמר. אחרי המסע הרקע עולה מהשחור אל עץ בהיר, ושם יושבים
תשעת השירותים.

## הפעלה מקומית

```bash
npm install
npm run dev
```

## בנייה

```bash
npm run build
```

## מבנה

| נתיב | מה יש שם |
| --- | --- |
| `src/scroll-scrub-scenes.ts` | הפרקים של הסרט: הקליפים, הכותרות והמלל |
| `src/site-content.ts` | תשעת השירותים ורשימת העמודים לתפריט |
| `src/components/scroll-scrub/` | מנוע הגלילה שמריץ את הווידאו |
| `src/components/after-film.tsx` | החלק שאחרי הסרט: המעבר לעץ והשירותים |
| `src/components/site-menu.tsx` | תפריט ההמבורגר |
| `src/site.css` | כל העיצוב שנכתב לאתר הזה |
| `public/assets/world/` | הקליפים והפוסטרים |

## דברים ששווה לדעת לפני שנוגעים

- **הכתר מעל האות ה'** ממוקם לפי מדידה של הגופן (`src/site.css`, `.ss-crowned::before`).
  שינוי של הגופן, המשקל או גובה השורה מזיז אותו וצריך למדוד מחדש.
- **כל קליף מתחיל בפריים האחרון של הקודם.** אם מחליפים קליף, צריך לחלץ מחדש
  את הפריים ולהשתמש בו כנקודת הפתיחה של הבא, אחרת נוצרת קפיצה.
- **הפוסטר של כל קליף הוא הפריים הראשון של אותו קובץ מקודד**, לא תמונה אחרת.
